# Vcamp 1.0.0-rc.1 发布说明草稿

这是候选测试版本，尚未发布到 GitHub。正式 v1.0.0 应从最终冻结提交重新构建与验收，不能只重命名候选 ZIP。

Vcamp 将字幕、问答、Markdown 笔记、交互 HTML 学习页和本地资料管理放在视频侧栏中。AI 功能使用用户自备 Key，费用由服务商收取；项目不提供云同步或共享 Key。

本轮修复包括：随笔导出严格保持所选范围、文本模型携带图片历史时明确拒绝、不支持文本输出的模型录入保护、长文导出上限对齐，以及导出前检查备份能否被恢复。扩展启动动效移除 Remotion 运行依赖，Zod 已升级，生产依赖许可声明及自动检查已补充。

最低声明为桌面 Chrome/Chromium 149，本轮自动化使用 Chromium 149.0.7827.55。真实模型仅验证 DeepSeek 合成教材样本；其它服务商和所有真实视频不作一概通过的声明。真实站点字幕可能依赖登录、视频本身及网络条件，无字幕时不承诺完整音频转写。HTML 内容在沙箱内运行，内容仍需结合原视频核对。

下载时请选择 `Vcamp-1.0.0-rc.1.zip` 浏览器包，核对 `SHA256SUMS.txt`；GitHub 自动生成的源码 ZIP 无法直接加载。安装步骤见 [安装说明](../install.md)，证据见 [候选验收](validation.md)。正式上传时应同时提供构建清单与校验文件，并填入已验证的真实下载链接。

更新前先导出 `.vcamp` 备份。将生产文件替换到原安装目录后重新加载扩展；换路径、换 profile 或先卸载可能改变身份，需要导入备份并重新配置 Key。不要让旧版本直接操作未知的新数据库结构。

产品演示视频已暂停；内置角色、模板和系统文案可能后续版本化调整。当前未启用 GitHub 分支保护或私密漏洞报告入口，公开发布前仍需完成 [GitHub 门禁](github-setup.md)。
