## 绑定与媒体宿主方案

继续沿用生产 SourceBinding：platform/videoId/partId/tabId/documentId/epoch；请求源身份冻结，另记录执行宿主 binding。结果返回原任务目标，不给新页面写回字幕或帧。sourceBinding 失效后不能“重绑”请求到当前视频。

预测计划未知时仍需要保有原媒体；仅冻结当前图片、捕获可见窗口、保存原页 blob URL，都未证明能够在原文档销毁后获得后续任意时间帧。先用 source-only 实验证明失败，才验证一个临时原站点标签。该路线让站点自己的播放器和媒体请求继续正常工作，不创建平行数据库、不下载整个视频、不复制产品壳层、不假设 MSE blob 能跨文档使用。授权范围必须明确允许本次原媒体的临时宿主；activeTab 的临时权限不会自动转给新标签，生产 broker 应使用用户授予的站点权限并显式确认宿主策略。

临时标签 inactive + muted，完成／失败 finally 删除；会增加标签条项目、网络和内存，本轮不把它包装为无副作用的 offscreen 页面。offscreen/iframes/直接 CDN 解码均 **not-run**；已有最小可行实验路径，没有证据要求引入更复杂宿主。关面板保活／Worker 停止等由 R1 和消费者后续实际联验解决，本轮没有 GenerationPort 状态机。

首个固定候选复跑出现 2/6 X1 失败：媒体宿主仍同 BV/cid，但初始化后 documentId 变化，早期冻结的执行绑定被拒绝。实验增加连续两次稳定文档／媒体观察和 duration 对照，并保留失败证据；不会改原任务来源或在来源标签返回旧页时才继续。另加入 seek 前注册的视频帧呈现回调，画面时间和合成像素单独复验。候选 runner 现在会因 X1 能力失败返回 1，不把执行完脚本写成能力 pass。最终结论只绑定报告列出的修订 TARGET。

字幕原始正文、带签名的轨道 URL只内存使用，扩展 fetch no-store；输出统计和指纹，不建立字幕磁盘缓存或备份。source page 自身／浏览器的正常缓存和登录 profile 不等于扩展资料持久层；整个 profile 都不提交。错误包括 no-subtitles/read-failed/auth-failed/permission-denied/stale-binding/capture-failed；canvas污染、无解码画面、seek失败、用户竞争保留具体 reason。

## W1-R2-FIX-02：把不可观测的恢复意图移出用户播放器

固定审查证明：站点预先缓存v.pause.bind(v)，在取帧暂时暂停期间调用，原生不会重复发pause事件；调用也不经过后装元素包装。直接HTMLMediaElement.prototype.pause同样存在这条边界。实验无法可靠区分“用户没有操作”和“有无事件pause意图”。继续包装原型或增超时不能解决信息缺失。旧失败记录保留，限定为合成站点复现，不声称B站采用相同缓存代码。

最终调用路径：公开capture(null)对原页面只读draw，不安装descriptor；公开capture(time)必须取得现有临时原站点标签lease再取帧。acquire在source身份有效时创建inactive about:blank，muted后导航原URL；连续两次稳定身份／duration后注册executionBinding并只暂停宿主。原播放器全程没有取帧写操作，新pause/seek以及无事件调用自然保留；无新操作时原playing也不会被无条件暂停。source与host独立，结果标明两种binding，底层before/after/restored只属于host。acquire可先于帧计划；切视频后captureLease继续原媒体任务，新空间并发操作。授权新增实验字段allowTemporaryHost:true，拒绝不建host；没有扩大生产manifest或共享类型。

释放：公开单次capture在finally release；显式lease驱动也finally release。准确取消由原binding/requestId定位，初始化检查cancelled；ready后取消底层操作并销毁自己的宿主覆盖注入竞态。captureLease每lease只允许一个操作；release重复为not-found，真实tab已被关闭也记录already-closed。测试覆盖取消、宿主被关闭、部分descriptor安装失败、后续请求及source/host清理。控制页失联／进程强杀仍由R1后续生命周期联验，不伪称本轮已覆盖。

STD-R2-FIX-01：安装成功后记录original和installed完整descriptor；finally只有当前value/get/set/writable/enumerable/configurable都等于installed才恢复original。期间站点replace/delete/flags/accessor/nonconfigurable变化保留，不按属性存在性强行覆盖。已有nonconfigurable可使低层安装失败，但释放已经拥有的包装／监听／锁；只读current无需安装。原13项和QA5项仍针对实际低层adapter、隔离路线另22项验证用户语义，两层不混称同一个测试。

已拒绝的路线：继续在用户播放器临时pause再猜隐藏意图；永不恢复／一律暂停；全局原型拦截。保留captureInDocument仅作为可销毁宿主的底层诊断接口，它不承诺用户播放器缓存无事件意图安全；公开路线不在source调用有时间的该接口。源码修改限实验，未变字幕／页面身份／鉴权，不重新用户登录，历史字幕证据不得标成本轮复跑。

宿主副作用仍未获生产接受：标签条创建/关闭、站点初始化和媒体请求、额外内存/网络。实验自动核验inactive、muted和活动标签不变；下一步用户可观察一次请求开始/取消/完成的标签创建关闭、是否抢焦点或发声，并由总控决定生产策略。内存峰值/网络成本未量化，R1关面板/Worker及真实Chat/模型仍not-run。通过技术回归不批准产品副作用或放行T02/T15/T16。
