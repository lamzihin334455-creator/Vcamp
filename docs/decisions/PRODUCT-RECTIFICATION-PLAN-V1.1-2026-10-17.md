## 需求基准与本次纠偏

1. 本轮用户明确需求优先。原审核HTML是既有视觉与交互依据，工程规格和当前代码不能覆盖它。
2. PRD记载的原始依据为 `[private local design reference]`；仓库 `vcamp-prototype.html` 与 `prototype/public/vcamp-prototype.html` 为后续原型载体。`prototype/design-qa.md`记录了保留原版样式、主题二级菜单和模块切换等验证。执行前先固定对照文件，后续版本有差异时只采纳已确认改动；不能仅因文件较新就把改动视为批准。
3. HTML是模型根据视频和用户需求直接生成的可阅读、可操作页面。页面自己的HTML/CSS/JavaScript承担交互，不再以固定JSON知识卡片及插件追问机制替代。本轮需求覆盖2026-10-15结构化知识方案中与之冲突的方向；旧报告保留，不当作新需求约束。
4. 当前只核对文档和部分源代码，尚未逐屏进行视觉差异验收。正式还原时需并排查看原型与真实扩展，避免仅凭代码或文字宣布“已还原”。

固定开发起点为集成分支 `codex/vcamp-integration` 的 `30168594eccae64f2f82be2c94eb3cc32e755b50`。现有安装包保留作回退，不覆盖用户数据。进入执行时如基线已更新，先登记实际新基线，不盲目覆盖。

## 第一阶段：还原原型，补齐交互设计

### 目标与范围

恢复已经确认的工作台，让用户先确认“界面是否正确、入口是否自然”。完成现有能力的UI接线及主题切换；HTML新引擎、视频识别机制等功能变更留到第二阶段。

| 工作包 | 对应整改项 | 交付内容 |
| --- | --- | --- |
| 顶部与模块结构 | 01、03、04、05、13 | 还原标题与内容切换一体入口；点击标题选择对话、文章和产物。删除独立“当前对话”栏。标题右侧随Chat、字幕、Markdown、HTML、随笔切换专属操作；必要的次要操作收进二级菜单，不在正文重复摆放 |
| 回答与输入区 | 01、06、07 | 还原回答布局、按钮、模型选择、产物选择及弹出方式；键入@唤起原型选择器，正确处理选择、取消和输入法，不以独立“@添加”按钮替代。保留原文本、引用、模板等已有能力 |
| 设置与主题 | 08、09、10 | 还原主题色及二级菜单；模板选择和编辑保持同组，API配置单独成组。自主识别移出输入区常驻说明，具体入口按下方待确认建议落实 |
| 内容空间整理 | 02、05、13 | 移除重复导航、重复操作和无须常驻的过程说明；核心正文获得主要空间。必要错误、进行状态、取消入口及确实需要的权限说明在相应操作处保留，不因简化页面丢失能力 |
| 原型未覆盖的交互设计 | 08、11、12、14—16 | 输出简短界面示意/可点击演示：自主识别入口、HTML生成与查看/重置、随笔时间块、授权状态、切视频状态。与现有页面放在同一套视觉中，标清演示状态，不伪称功能已实现 |

正文中的说明逐项处理为“删除重复文案、移到相关菜单/提示、必要时展示、待确认”四种结果。不能将错误、风险提示和权限能力一起删除，也不要求用户先审核一份巨大的文案表：只列真正有取舍的少量项。

原型已有按钮的位置、顺序、样式和动效按原型执行，不另造工具栏。原型没有的按钮布局才使用以下建议；用户未确认前不写入正式交互。

### 待确认设计建议

| 项目 | 建议方案 | 确认前的处理 |
| --- | --- | --- |
| 自主识别设置 | 放在设置菜单独立“视频理解”二级项中，与模板、API分组并列；涉及单次取帧的必要确认仍在实际使用时出现 | 移位设计先演示，不删除功能或提前绕过权限 |
| HTML查看与重置 | Chat生成完成后提供“打开页面”，用户主动进入HTML模块。模块标题右侧“重置”重新加载已保存的原始页面，使页面内交互回到初始状态；不重新调用模型、不覆盖保存源码 | 重置是拟定语义；不做自动重新生成或额外AI追问栏 |
| HTML页面支持范围 | 首版建议自包含HTML/CSS/JavaScript，支持页内展开、筛选、测验、图表等本地交互；窄栏适配和主题风格通过输出要求约束。外部脚本、自动联网和扩展数据访问不默认提供 | 这限制运行能力，不限制用户只能生成固定知识结构。若需求确需外部资源，单列具体场景决定 |
| 旧结构化知识成果 | 保留历史成果可读，不自动转换成HTML、不删除旧资料；从新HTML主流程移除复杂条目追问，旧入口是否保留在历史查看器内单列确认 | 旧存储/备份兼容先保留，不因清理界面破坏历史 |
| 随笔 | 同一正文区显示独立内容块，以视频时间升序排列；同一时间按创建先后排列，无时间的旧内容置末尾并保留 | 不新增文章分类/标签；旧数据含义不明时不重写时间 |
| 视频切换反馈 | 已检测到变化、尚未取得新身份时简短显示“正在切换视频…”，暂不允许以旧上下文发送；识别成功后恢复该视频/P的最近对话，无对话才创建默认对话 | 避免旧标题/新字幕混用；不加常驻技术状态面板 |

### 第一阶段交付与用户测试清单

交付：一个可安装体验包、原型对照截图、待确认设计示意，以及仅包含本批变化的说明。尚未实现的新HTML运行行为明确标成演示，不以旧知识文档冒充新HTML功能。

- [ ] 顶部标题可打开内容列表；切换对话/产物正确，没有独立重复选择栏。
- [ ] 逐次打开Chat、字幕、Markdown、HTML、随笔：右侧操作随模块切换，其他模块不再常驻“新对话/联网”。
- [ ] 回答样式、模型选择和产物选择与审核原型一致；原有功能可继续使用。
- [ ] 输入@可选择/取消，输入中文和普通文本不受干扰，已有草稿内容不丢失。
- [ ] 主题色切换生效；模板、API菜单分组正确；自主识别入口设计位置清楚。
- [ ] 正文没有重复工具栏/说明；窄栏和拖宽后各看一次，菜单不越界、内容可读。
- [ ] 查看新增交互演示，确认HTML重置、旧成果处理、随笔和切视频状态方案。

用户指出差异后在本阶段修正；不因为第二阶段功能未开发判定原型还原失败。第一阶段结束条件是已约定还原项被用户认可，第二阶段会改变行为的设计已明确。单个待讨论增强项可延期，不连带阻断无关修复。

## 第二阶段：按正确定位实现产品功能

### 目标与工作顺序

在第一阶段已确认的界面上打通正确功能，不继续改变已验收布局。先做视频上下文与权限修正，再完成随笔及HTML功能，最终交付统一体验版本。

| 工作包 | 对应整改项 | 实施及完成标准 |
| --- | --- | --- |
| 视频身份与权限 | 15、16 | 已具备访问权限时直接读取可取得的视频基础信息，不重复请求授权；缺少浏览器权限时走必要授权，截图/外发等要求分别处理。视频或P切换及时识别并切换工作空间，恢复对应最近Chat；旧异步结果不能覆盖新视频。旧后台生成归原Chat，切换不丢草稿 |
| 随笔内容模型与展示 | 14 | 每次保存是一块，以对应视频时间顺序统一显示；不作为文章或知识分类条目呈现。保留现有必要编辑、时间定位和保存能力，旧内容可读取 |
| HTML生成与显示 | 11 | 复用现有Chat、视频资料、模型设置及生成任务；按用户要求和已获得的视频上下文生成自包含页面，加入视觉风格/窄栏适配/输出格式约束。用户主动打开后可直接操作页面本身，不再先转换为固定JSON知识结构 |
| HTML重置与保存 | 11 | 按第一阶段确认语义重置页内状态，无额外模型请求；保存页面原始成果，关闭重开仍能阅读和交互，接入既有资料库与备份，不建立第二套管理系统 |
| 追问机制收缩与兼容 | 12 | 新HTML界面不附加复杂“条目选择—快照—来源对话”流程；自然语言继续提问仍通过Chat。仅移除已确认不需要的入口和依赖，旧成果及历史请求保持可读，不清空用户资料 |

### HTML实现边界

这是本阶段需要做技术决策的一项，不能仅把旧JSON更名为HTML，也不能把模型脚本直接放到有扩展权限的页面执行。

采用可隔离的页面运行容器承载HTML/CSS/JavaScript，生成页与API Key、扩展存储、宿主页DOM分离；默认限制外部资源和网络，容器能卸载、重新创建。可使用浏览器已有隔离能力，不先建立通用脚本框架。旧R1记录中存在未解决的隔离/运行问题，实施者先查已有证据，只针对拟采用方案验证“页内交互可用、无法触达宿主数据、重置后初始状态恢复、异常页面可退出”这些必要边界。若仍不能满足，报告具体失败点和最小替代建议，不静默退回知识JSON、不启动开放式路线研究。

输出要求应约束内容完整、独立可显示、中文排版、主题与侧栏适配；格式截断/不支持时给简明失败说明，用户手动重试。不能保证模型每次内容和视觉完美，也不能用大量正文免责声明替代正确实现。真实生成只在用户体验或另有明确执行范围时使用API，不预设循环收费重试。

### 第二阶段交付与用户测试清单

交付：一个整合体验包、已改功能说明和遗留问题短表。工程侧只补受影响的验证；用户按下表体验即可，不承担协议、数据库或隔离测试矩阵。

- [ ] 已授权的视频正常读取，不再重复确认基础信息；缺权限时提示准确，必要截图授权仍在。
- [ ] 同页换P、切到另一个视频、返回原视频各做一次：标题、字幕、当前Chat同步正确，原草稿仍在。
- [ ] 连记三条不同时间随笔：每条独立，统一按时间排列，编辑及时间定位可用。
- [ ] 根据一个视频生成一份阅读整理HTML，再生成一份带自测题或筛选交互的HTML：均符合所提要求，页面内交互可直接操作。
- [ ] HTML内容可读、窄栏布局正常；主界面没有强加的知识分类/复杂追问操作。
- [ ] 操作页面后点击重置：回到初始状态，没有再次调用模型生成。
- [ ] 关闭重开并从资料库打开新页面；旧笔记和旧知识成果仍可读。新HTML做一次备份导出/导入验证，已有资料不被替换或丢失。

发生问题只记录所在步骤、实际结果和预期效果；修复后只复验该项及直接关联项。阶段二完成以用户认可核心闭环为准，不把所有历史兼容检查升级为本轮前置条件。
