## 复现

在源码根目录对应的干净检出中执行：

```sh
cd extension
npm ci --ignore-scripts
npm run typecheck
npm test
npm audit --omit=dev --audit-level=high
npm run build
npm run licenses
npm run package
npx playwright install chromium
npm run test:package
npm run test:e2e
```

自动化默认使用隔离浏览器与合成响应，不要求真实 Key。旧生产目录升级用例需显式设置 `VCAMP_UPGRADE_FROM`；私有资料重放需显式设置对应本地文件变量，未设置时的跳过不能当作通过。
