# 本次 AI 指令查看器

交付版本：0.1.21，2026-10-20。沿用固定规则目录 `2026-10-20.v2`，不修改 P0–P3 优先级、输出协议、HTML 隔离或字幕处理规则。

## 两种查看状态

- 发送前：输入区的「查看本次 AI 指令」。展示当前角色、模板、额外要求、预计最终规则、当前字幕、候选历史、已选引用与图片。角色/模板可跳转管理页编辑或复制；规则只读并有作用、生效条件和版本说明。尚未取得的网页、取帧及资料规划不会被当作已发送内容。
- 发送后：用户消息或字幕任务上的「本次 AI 指令」。按真实 API 调用分阶段展示资料规划、取帧规划、网页检索、Chat/Markdown/HTML 最终生成、字幕纠错/翻译；提供完整请求文本复制。HTTP 状态仅代表网络层结果，不代表模型生成成功。

发送后的角色与模板来自任务快照。修改当前配置不改写旧请求；编辑入口只在发送前配置中提供。重试显示为另一次尝试，沿用原冻结角色/模板，实际固定规则取自该次执行。旧任务、导入任务或已过期记录不做事后重建，明确显示没有实际调用记录。

## 记录来源和数据边界

`tracedTransport` 包装现有 Provider 和网页检索使用的 fetch，在序列化请求实际交给网络层时观察请求体。原 URL、请求头、正文、AbortSignal、返回 Response 和错误继续原样传递，不追加模型调用、不读响应内容、不改变生成队列。

- 系统规则正文从已发出的 system 标识提取；动态取帧范围、规则版本等随记录冻结，展示时不使用当前目录替代旧记录。
- 保存模型、messages、system、stream、thinking、stream_options、max_tokens、response_format、tools、tool_choice。这是当前所有请求体字段；新 Provider 参数需要同步扩展允许列表及测试。
- 不采集请求头、密钥、Cookie、模型输出或内部思考。正文中与当前密钥完全相同的字符串替换并明确标注脱敏。
- PNG 字节替换为 SHA-256 与字节数；通过已有附件服务核对指纹后查看原图，避免重复存储图像。原附件不可读时保留指纹并提示。
- 上下文按视频、主字幕、补充资料、网页、历史和任务消息展示；请求 JSON 保留消息顺序及文字，以便逐项核对。字幕批次索引和时间仍来自实际发送的正文。
- 缓存位于 `chrome.storage.session`：最长24小时、最多60次调用、最多4MiB，先清理较早记录。浏览器重启、扩展重载或更新可清空；Worker 暂停不以重建文本替代记录。缓存不进入数据库、备份或诊断日志，记录失败不阻塞或重复 API 调用。
- 只允许交互侧栏读取；页面内容脚本、只读阅读器不能查询。查询核对任务所属 workspace/chat，并复用删除检查。

## 实现位置

- `extension/src/contracts/instructions.ts`：查询协议和严格 schema。
- `extension/src/generation/instruction-trace.ts`：脱敏、按调用记录、限额和规划关联。
- `extension/src/generation/instruction-service.ts`：权限与快照查询、附件指纹匹配。
- `extension/src/workbench/Instructions.tsx`：发送前/后查看界面。流式更新期间最多每500ms触发一次刷新。
- `executor.ts` 与 `evidence-preparation.ts`：复用现有实际网络边界。没有新权限、数据库迁移、额外 API 请求或提示词内容改写。

## 已验证与保留取舍

完整单元测试335项通过；类型检查、生产构建通过。安装包浏览器测试覆盖角色/模板编辑复制删除、发送前不调用 API、真实请求文本一致、角色切换后旧快照不变、会话缓存清空、取帧指纹与原附件对应、字幕两类协议与时间、HTML 定位和多语导出。

这是有上限的会话调试记录，不是长期审计存档。大型请求超出单记录500000字符校验或缓存写入失败时，生成仍继续，查看器可能没有记录；无记录不能证明没有发送。发送前显示候选配置，完整实际清单只能在网络请求发生后获得。未进行付费真实模型调用，模型表达质量和复杂自定义指令的效果留给人工测试。
