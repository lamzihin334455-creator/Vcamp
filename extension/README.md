# Vcamp

围绕 Bilibili 视频学习的 Chrome 侧栏工作台。支持字幕阅读、增强、翻译与导出，视频问答、Markdown 笔记、交互 HTML 学习页、截图与自主视觉、角色和任务模板、涂写、资料收藏、回收站及备份恢复。

当前候选版本 **0.1.69**，主要在 Windows / Chromium 149 验证。manifest 最低版本 Chrome 116 不代表已完成旧版本验收。AI 使用自己的服务商 API Key，费用由服务商计算。

## 安装与开发

使用 Node.js 24 与 npm，在本目录执行：

```sh
npm ci --ignore-scripts
npm run typecheck
npm test
npm run build
```

在 chrome://extensions 开启开发者模式，加载已解压的扩展程序，选择本目录 dist。打开 Bilibili 视频后点击扩展按钮打开侧栏。主菜单「设置」的「API 设置」一行右侧可直接选择所有连接中已录入的模型，名称后注明服务商；选择时自动切换对应 Key。同一服务有多个 Key 时还会标注连接名称。模型与角色均支持右侧单行省略显示、展开列表与直接选择；点击左侧「角色设置」进入角色管理。设置顺序保留主题颜色、对话偏好、角色设置、API 设置、模板工作流。点击左侧「API 设置」进入管理页，顶部同样可直接选模型，下方先连接服务并保存 Key，再在「管理模型」中选择已保存的连接，拉取模型并勾选录入。保留窄屏纵向分步卡片；录入后自动使用默认模型，可直接返回。已录入列表支持逐个删除，删除后同步移出切换列表。角色和模型切换浮层均无搜索框，API 页浮层与选择栏等宽对齐。每个 Key 独立保存目录、录入结果与默认模型；旧版已可用模型会保留为已录入模型。字幕取决于站点实际提供情况及登录状态。

提供 DeepSeek、阿里云百炼、硅基流动、智谱 AI 和自定义 OpenAI 兼容 HTTPS Base URL。预设地址可编辑，首次保存新地址时请求该来源的访问权限。百炼默认北京公共域名；其它地域或业务空间请按控制台提供的 Base URL 修改。第三方列表接口不可用时，可手动录入完整文本模型 ID；这不代表连接已验证。

DeepSeek V4.1 为专项优化目标。DeepSeek 官方服务保留原有联网与按服务声明开放的视觉能力；联网需在当前 Key 下录入 deepseek-flash。其它服务商及自定义地址仅启用 OpenAI 兼容流式文本，暂不开放联网和视觉，文本输出预算上限 8192 tokens。模型能力不根据名称猜测；带图片历史的对话需使用支持视觉的原服务或新建文本对话。

## 测试

```sh
npx playwright install chromium
npm run test:e2e
```

E2E 自动构建隔离生产候选、测试版与媒体测试版，不覆盖开发者已安装的 dist；使用合成凭据、媒体与受控响应，无需真实 Key。不要发布 dist-test 或 dist-capture。

## 数据和限制

资料保存在本机扩展 IndexedDB，卸载或清除数据可能丢失，请主动备份。Key 配置位于限制为可信扩展上下文的 chrome.storage.local，不随资料备份导出；它不是系统密钥保险箱。发起模型任务会按需要向当前配置的服务地址发送视频资料、问题、所选引用和附件；DeepSeek 视觉会采集画面，联网可能发送检索问题。详见根目录 PRIVACY.md 与 SECURITY.md。

字幕增强/翻译最多 16 批，每批最多 40 条或 4000 字符；另有整体文本及附件预算。视频时长不能代替字幕容量或证据覆盖率。没有字幕且只有少量静帧时，无法可靠概括全片。模型可能超字数或误引时间，生成成功不等于内容正确。

角色和模板按版本冻结，升级不会改写用户编辑、历史任务或旧选择；旧角色显示历史版本。本项目自身许可证待作者确认，依赖许可见 THIRD_PARTY_NOTICES.md，尤其 Remotion 条件。公开上传前请核对发布审查未决项。
