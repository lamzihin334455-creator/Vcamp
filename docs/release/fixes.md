## 陈旧测试调整

旧测试将 provider.fetch 当作自动录入，使用了已移除的模型按钮、菜单和字幕刷新入口，或断言旧视觉核验预算。修正为当前公开工作流：目录 → 勾选录入；应用模型选择器；字幕标题栏刷新；独立主/辅助字号。保留原测试行为目标，关键授权、持久化、时间定位、数据完整性断言不因失败而删除。

历史备份测试继续验证旧的图片过滤快照；当前生成则显式使用视觉能力，不重新制造文本模型静默丢图片的旧行为。未支持的模型录入测试改为先断言拒绝，再验证合法模型的跨 Key 选择。

## 审查限制

报告包含完整文件清单与重点边界审查，并未声称每一源码行均经人工复核。未实现的资源消耗硬隔离、未知浏览器行为及模型内容正确性属于已知限制。独立修复后复审因服务审核拒绝未完成，定向和完整自动化证据单独记录。
